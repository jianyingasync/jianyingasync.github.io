1. 下载与安装

  1. 点击下载：http://180.184.168.232:18888/download/KeyMirrorSetup.exe
  2. 运行 KeyMirrorSetup.exe，按向导安装。默认装到当前用户目录，一般不需要管理员权限。
  3. 安装完成后，从桌面「键影同步」快捷方式启动。
提示：安装包自带线上接口配置，登录请求的是服务器，不是本机。若已装过旧版，直接覆盖安装后再打开即可。

2. 注册 / 登录

图 1：登录窗口（蓝色序号对应操作说明）。

  1. 手机号：输入本人手机号。没有账号时，点右下角「没有账号？注册」。
  2. 密码：输入密码。可勾选「记住密码」，下次自动填好。
  3. 用户协议：必须勾选「已同意《键影同步用户协议》」才能继续。点蓝色协议名可查看全文。
  4. 验证码：输入右侧图形验证码；点验证码图片可刷新。
  5. 点蓝色「登录」或注册页的「注册」按钮。
注意：同一个账号同时只允许一处在线。在别处登录时，这边会退出，请注意账号安全。

新注册用户会开通约两日试用（能力以个人中心显示为准）。试用结束后仍可登录为普通会员，方便打开个人中心了解续费。

3. 游戏准备（很重要）

先把游戏改成窗口化。推荐使用 1024×768 像素的窗口。不要最小化，也不要用全屏独占。
  1. 先打开要同步的多个游戏客户端（例如 2～5 个）。
  2. 每个窗口都调成窗口化，分辨率尽量一致。
  3. 再打开键影同步。同步器不会缩放游戏窗口：左侧操作区跟着当前游戏客户区的原像素大小变化，能放进去就把游戏窗口贴到左侧。

4. 认识主界面

图 2：主界面总览。

序号区域作用
1刷新 / 筛选 / 自动绑定刷新窗口列表，按游戏名过滤，一键按顺序绑定槽位
2开始同步打开或停止键鼠同步
3一键跟随 / 一键钓鱼跟随队长、新飞飞钓鱼等快捷操作
4个人中心 / 客服查看会员、改密码；和客服发消息（有回复时有红点）
5左侧操作区当前槽位画面。可在此点击、按键；上方有「还原位置」
6右侧槽位列本组 1～5 号预览；SVIP 可切换第一组 / 第二组
7下方窗口池可拖拽排序、双击绑定、改备注

5. 筛选、排序与绑定

5.1 工具栏：刷新、筛选、自动绑定

图 3：顶部工具栏局部。

  1. 点「刷新列表」。同步器会枚举当前可见窗口；筛选里若含「飞飞」，还会尝试识别角色名（窗口可能短暂闪一下）。
  2. 在「筛选」框输入游戏名关键字（例如「新飞飞」），只显示匹配的窗口。
  3. 窗口排好序后，点「自动绑定」，按窗口池顺序填入当前组槽位。

5.2 窗口池：拖拽排序

图 4：下方窗口池。

  1. 按住卡片拖拽，调整从左到右、从上到下的顺序。
  2. 自动绑定会按这个顺序依次放入槽位 1、2、3…
  3. 也可先点右侧某个空槽位，再双击窗口池卡片，手动绑到该槽位。
  4. 可为窗口添加备注，方便辨认角色。

5.3 右侧槽位

图 5：本组槽位预览。

  1. 单击某个槽位，左侧切换为该窗口的操作区。
  2. SVIP 可在「第一组 / 第二组」之间切换，两组分别绑定。
  3. 「清空本组」会解除当前组绑定，并把窗口放回绑定前记录的位置。
槽位 1 一般当作队长 / 主号。一键跟随时不会点槽位 1，而是让槽位 2～5 去跟队长。

6. 开始同步

  1. 至少绑定 2 个 窗口（普通会员只有预览，不能多开同步）。
  2. 确认勾选了「同步键盘」和 / 或「同步鼠标按键」。
  3. 点绿色「开始同步」，按钮会变成「停止同步」，状态显示「同步中」。
  4. 到任意一个已绑定的游戏窗口里操作，其余窗口会跟着做同样的键鼠动作。
  5. 也可以点左侧槽位画面，在同步器里直接操作当前槽位。
  6. 不需要时再点「停止同步」。
快捷键：同步器或已绑定游戏在前台时，可用 Ctrl+Shift+F8 开关同步；数字键 1～5 快速切换槽位。
还原位置：窗口位置乱了时，点左侧上方「还原位置」，游戏窗口会回到绑定前记录的位置。

7. 一键跟随 / 一键钓鱼

7.1 一键跟随

  1. 先点「开始同步」。
  2. 第一次点「一键跟随」时，按提示按下游戏里的跟随键（例如 F4 / F5），同步器会记住，按钮上会显示键名。
  3. 之后再点，会让当前组槽位 2～5 依次点中队伍列表第 4 个头像（队长位），并按下跟随键。
  4. 右键「一键跟随」可清除已记录的跟随键，下次重新设置。

7.2 一键钓鱼（新飞飞）

  1. 仅当筛选内容包含「飞飞」时，工具栏才会出现「一键钓鱼」。
  2. 先让各角色进入钓鱼界面 →「开始同步」→「一键钓鱼」。
  3. 会对当前组已绑定窗口持续发送方向键「下」；再点一次停止。

这是针对部分游戏的定制能力。若需要其他场景，可联系客服说明需求，可免费沟通定制。

8. 日常操作小技巧

  • 窗口置顶：勾选后同步器留在最前面，避免被游戏挡住。
  • 左侧画面：按当前游戏客户区原像素显示，不把游戏强行缩放。放得下就贴进左侧；放不下请把游戏改成推荐分辨率后再绑。
  • 管理员运行：若游戏是管理员权限启动、同步器不是，可能导致按键送不进去。可用工具栏「管理员运行」。
  • 组切换：SVIP 两组各五个窗口；切换组后，绑定与同步针对当前组。

9. 个人中心与客服

图 6：个人中心。

  1. 点右上角头像或会员标签，打开个人中心。
  2. 可查看当前等级、开始时间、有效期、可开窗口数；需要时点「续费升级」。
  3. 底部可「退出登录」「意见反馈」「修改密码」。
  4. 点客服图标打开会话。客服回复后图标会出现红点，点开后消失。
  5. 客服服务时间：8：00－16：30。也可扫码主动加客服好友。

10. 会员等级说明

等级窗口能力说明
普通1 个预览可登录查看；不能多开同步
VIP一组五开5 个槽位，1 组
SVIP两组十开每组 5 个，共 2 组

注册试用一般为短期 SVIP 能力；到期未续费会变为普通。付费会员过期后登录可能被限制，请联系客服或管理员续费。

11. 常见问题

左侧点不准？

请确认游戏是窗口化，且分辨率正常。当前版本左侧按游戏原像素贴入，不缩放游戏。若窗口以前被拉变形，先点「还原位置」，或在游戏里重新设成 1024×768 再绑定。

看不到窗口 / 绑定不上？

检查筛选关键字是否过窄；窗口是否最小化；刷新列表后再试。

开始同步提示不能同步？

普通会员不能多开同步。请确认至少绑定两个窗口，并勾选键盘或鼠标同步；VIP / SVIP 才可多开。

一键跟随没点到？

保持槽位 2～5 窗口化且可见；槽位 1 是队长不会被点。确保队伍界面开着，且已开始同步。

杀毒软件拦截？

同步器需要枚举窗口并发送键鼠消息，部分安全软件会误报。请从官网地址下载，并加入信任后安装。

可以定制特殊游戏场景吗？

可以。联系客服说明需求，可免费沟通定制。
